# Misc Utilities

Miscellaneous utility scripts for common 3ds Max modeling tasks.

## Available Scripts

* [Align Pivot to Face Normal](Align%20Pivot%20to%20Face%20Normal) - Aligns an object's pivot point to the normal of a selected polygonal face.
* [Boolean_Extract Operand](Boolean_Extract%20Operand) - Extracts a Boolean operand from a Boolean compound object.
* [Copy Paste](Copy_Paste) - A clipboard-style utility for copying and pasting objects between 3ds Max scenes.
