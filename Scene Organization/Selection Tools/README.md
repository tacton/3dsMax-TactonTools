# Selection Tools

A collection of methods for selecting objects or refining an existing selection.

![](<Selection Tools.jpg>)

## Sections

### 1. Selection Options

Global options that modify the behavior of other selection tools.

- **Include Hidden** — Includes hidden objects in the selection. Works with **Selection by Object** and **Selection by Color**.
- **Keep Current Selection** — Adds to the existing selection rather than replacing it. Currently works with **Selection by Object** only.
- **Open Groups of Selection** — Opens the groups of any selected objects.

### 2. Selection by Object

Selects the most common object types and instances belonging to any selected object. Also provides options to remove specific object types from the current selection, such as helpers, splines, and instances.

### 3. Selection by Color

Selects objects or helpers by their wireframe color. Also includes an option to select objects with no material applied.

### 4. Misc Selection

Selects objects by **triangle count** or **volume**. Respects the **Include Hidden** checkbox.
