# 3dsmax-scripts

A collection of MaxScript tools and utilities developed by Tacton Labs for use in 3ds Max visualization workflows.

## Script Categories

* [CAD Object Tools](CAD%20Object%20Tools) - Tools for working with imported CAD mesh data, including detaching, mirroring, and two-sided mesh management.
* [Helper Tools](Helper%20Tools) - Tools for managing helper objects, docking points, and pivot alignment.
* [Import and Export Tools](Import%20and%20Export%20Tools) - Automated import/export workflows for FBX, DAE, OBJ, STEP, and CAD formats.
* [Material and Mapping](Material%20and%20Mapping) - A comprehensive suite of tools for material management, UV mapping, and texture assignment.
* [Misc Utilities](Misc%20Utilities) - Miscellaneous utility scripts for common 3ds Max tasks.
* [Normals](Normals) - Tools for managing mesh normals and custom attributes.
* [Scene Organization](Scene%20Organization) - Scripts for scene organization including object naming, layer management, and group handling.

## Installation

See the [installation guide](installation) for step-by-step instructions.
> **Note:** Tacton Tools MaxScripts were tested on 3ds Max 2024 and newer. Any MaxScripts requiring a newer version will be noted in the tool's documentation.
