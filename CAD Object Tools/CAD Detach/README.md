# CAD Detach

After installation, this tool can be found under **Toolbars** category > **Tacton Tools**.

![](<CAD Detach Tools.jpg>)

## How to Use

**Detach CAD from Selection** — With elements selected, pressing this button will remove the selected element(s) from the object.

**Explode Elements** — Detaches all elements in the selected object into individual objects.
