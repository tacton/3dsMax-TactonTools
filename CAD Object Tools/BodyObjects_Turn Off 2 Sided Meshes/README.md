# Body Objects - Turn Off 2 Sided Meshes

A simple utility to turn off 2-sided meshes on Body Objects where that setting has been inadvertently enabled.

![](<Body Object_Turn Off 2 Sided Meshes.jpg>)

## Overview

On rare occasions, Body Objects will have 2-sided meshes turned on — most commonly when a Body Object is copied. This setting is not exposed in the 3ds Max UI and can only be corrected by script.

## How to Use

Select the offending Body Object and press **Two Sided Off**.
